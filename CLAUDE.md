# StaticHub — Agent Guide

Personal static-site hub. A repo of standalone mini-sites; `build.js` generates a root
`index.html` "hub" listing each as a card. Push to `main` → GitHub Actions builds + deploys to Pages.

## Facts
- **Repo:** https://github.com/bfos/StaticHub (public, owner `bfos`, default branch `main`)
- **Live:** https://bfos.github.io/StaticHub/
- **Pages:** enabled, source = GitHub Actions (`build_type=workflow`). Already configured.
- **gh CLI:** authenticated as `bfos` (scopes: `repo`, `workflow`). Use `gh` for all GitHub ops.
- **No dependencies.** `build.js` uses only Node built-ins (`fs`, `path`). Node 20 in CI.

## Layout
- `build.js` — scans `sites/` for subfolders containing an `index.html`. Reads optional
  `sites/<x>/site.json` `{title, description}` (falls back to folder name). HTML-escapes all
  metadata, sorts cards by title, writes root `index.html`. Skips entries starting with `.` or `_`
  and `node_modules`. Renders an empty-state when no sites. Cards link to `./sites/<folder>/`.
  Also **injects the hub overlay** into every deployed site page (see below). Exports its
  functions for tests; `main()` only runs when executed directly (`require.main`).
- `hub-overlay.js` — shared "return to hub" overlay (repo root). Vanilla JS, no deps. Renders a
  small fixed **bottom-left "← Hub" pill** inside a **Shadow DOM** (styles isolated from/​to the
  host site). Reads its target from a `data-hub-root` attribute the build bakes into its `<script>`
  tag. Hidden in print; respects `prefers-reduced-motion`; mobile safe-area insets.
- `test/build.test.js` — `node --test` unit tests for the injection helpers (`injectOverlay`,
  `relativeRootPath`): insertion, idempotency, stale-block replacement, depth/forward-slash paths.
- `sites/` — one folder per mini-site; deployed at `/sites/<folder>/`.
- `sites/_template/` — copy-to-start scaffold; skipped by build (`_` prefix). No manual back-link —
  the build injects the hub overlay into copies automatically.
- `.github/workflows/deploy.yml` — on push to `main` (+ manual): `node build.js` →
  `upload-pages-artifact@v3` (`path: .`) → `deploy-pages@v4`. Has `permissions` (contents:read,
  pages:write, id-token:write) and `concurrency: pages`.
- `package.json` — `"build": "node build.js"`, `"test": "node --test"`, no deps. `.gitignore` — `node_modules/` only.

## Hub overlay
- `build.js` injects, into every `.html` under each deployed site, just before `</body>`:
  `<script src="<rel>/hub-overlay.js" data-hub-root="<rel>/" defer></script>`, wrapped in
  `<!-- hub-overlay:start -->`…`<!-- hub-overlay:end -->` markers. `<rel>` is the per-file relative
  path to the repo root (forward-slashed), so it's correct at any nesting.
- **Idempotent:** the marked block is *replaced* on each build, so re-running changes nothing unless
  the relative path changed. Never injected into the root `index.html` or skipped folders.

## Rules / gotchas
- **Root `index.html` is generated** — committed but regenerated by CI on every push. Don't hand-edit it.
- **Site `.html` files are build-modified too** — the build injects/refreshes the marked hub-overlay
  block in each. Don't hand-edit inside the `<!-- hub-overlay -->` markers; change the overlay's look
  in `hub-overlay.js` instead. Editing a page's real content is fine — the build only touches the block.
- **Every site folder MUST contain `index.html`** — build requires it and Pages serves it as the folder default.
- **Add a site:** copy `sites/_template/` → `sites/<name>/`, edit `site.json`, add content, push.
- **Site content belongs to the user** — don't rename/edit files inside `sites/*` without confirming.
- Pushing is public. Confirm before publishing content you didn't create.
- **Windows / Git Bash:** `gh api` with a leading-slash path gets rewritten to a filesystem path —
  use `gh api repos/bfos/StaticHub/...` (no leading slash). LF→CRLF git warnings are harmless.
- Commit messages end with: `Co-Authored-By: Claude Opus 4.7 <noreply@anthropic.com>`

## Dev loop
- Build locally: `node build.js`. Run tests: `npm test` (`node --test`). Watch a run: `gh run watch <id> --exit-status`.
- Verify deploy: `curl -s https://bfos.github.io/StaticHub/` (check card titles + `/sites/<x>/` → 200).
